## 📌 How to Run This Project

1. Download or clone this repository.
2. Make sure the following files are in the same folder:
   - `index.html`
   - `style.css`
   - `profile.jpg`
3. Open `index.html` in your web browser.

---

## 🖼️ Profile Picture

Replace the `profile.jpg` file with your own image if needed.  
Make sure the file name matches the one used in the HTML file.
